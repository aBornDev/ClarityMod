# ClarityMod

A [Wizard of Legend](https://store.steampowered.com/app/445980/Wizard_of_Legend/) mod that rewrites the in-game descriptions of relics, arcana and outfits so they actually tell you the numbers: damage percentages, status effect levels, cooldowns, caps and hidden interactions.

Current version: **0.7** (continuation of Dawnbomb's Clarity v0.6).

All credit for the original mod goes to **Dawnbomb** (coding help by Zandra and Judgy). Dawnbomb has stopped modding Wizard of Legend and gave permission for the community to continue development of this mod.

## Installation

Requires the [Partiality launcher](https://github.com/PartialityModding/PartialityLauncher) set up for Wizard of Legend.

1. Download the latest release from the [Releases page](https://github.com/aBornDev/ClarityMod/releases). If no release has been published yet, build from source (see below) — the build output already has the right layout.
2. Copy `Wizard Of Legend Clarity Mod.dll` **and** the `ClarityData` folder into the `Mods` folder of your Wizard of Legend install, keeping them next to each other.
3. Enable the mod in the Partiality launcher and apply.

**Upgrading from 0.6:** since 0.7 the descriptions live in the `ClarityData` folder, not inside the DLL. If you replace only the DLL, the mod will load but won't change any descriptions (it logs `[Clarity] Could not find the ClarityData folder` to the Unity player log). Always copy the `ClarityData` folder along with the DLL.

## Editing descriptions (no programming needed)

As of 0.7 all description text lives in plain JSON files in [`Wizard Of Legend Clarity Mod/ClarityData`](Wizard%20Of%20Legend%20Clarity%20Mod/ClarityData), split by type:

| File | Contents |
| --- | --- |
| `Relics.json` | Relic descriptions, one entry per relic |
| `Arcana.json` | Arcana (spell) descriptions, tagged by category (Basic, Dash, Fire, ...) |
| `UIText.json` | Outfit / stat descriptions shown in the wardrobe |

Each entry looks like this:

```json
{
  "id": "DamageUp",
  "name": "Amulet of sundering",
  "description": "Increases <color=#f93d09>all Damage by 8%</color>!"
}
```

- `id` is the internal game ID — don't change it.
- `name` (relics) and `category` (arcana) are reference info for editors; the game ignores them.
- `description` is the text shown in game. It supports Unity rich text tags such as `<color=#c60d0d>...</color>`.
- Arcana entries may also have an `empowered` field with extra text appended when the arcana is enhanced.

Edit the files, save, restart the game — no recompiling needed. Numbers and effects can be cross-checked against the [Wizard of Legend wiki](https://wizardoflegend.fandom.com/wiki/Relics). Pull requests with corrections and missing entries are welcome.

## Building from source

The project targets .NET Framework 3.5 and references assemblies from your game install. It expects these files three folders above the repository (adjust the `HintPath`s in the `.csproj` to match your setup):

- `Assembly-CSharp.dll` and `UnityEngine.dll` / `UnityEngine.UI.dll` from `WizardOfLegend_Data/Managed`
- `HOOKS-Assembly-CSharp.dll` generated by Partiality
- `Partiality.dll` from the Partiality launcher

Open `Wizard Of Legend Clarity Mod.sln` in Visual Studio and build. The `ClarityData` JSON files are copied next to the built DLL automatically.
